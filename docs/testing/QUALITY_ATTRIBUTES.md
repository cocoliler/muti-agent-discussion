# 质量属性与测量目标
以下是验收目标，非实测结论。基准环境约定Windows11、4核CPU、16GB RAM、SSD、桌面Chromium，1920×1080，记录实际型号/版本。
网络模型耗时独立测量，不计入本地数据库或编排延时。

| ID / 优先级 | 目标 | 测量方式 |
|---|---|---|
| Q01 P0 类型/契约 | 未知字段和非法引用100%被拒绝；生成TS无漂移 | Schema边界、OpenAPI生成diff及类型构建 |
| Q02 P0 编排 | 100任务/1000边输入的纯校验+编排p95≤200ms | 随机合法/非法抽象图，预热10次测100次，不含网络 |
| Q03 P0 持久化 | 100任务计划保存p95≤500ms；失败无部分写入 | 临时本地库，连续100次+注入事务失败 |
| Q04 P0 画布 | 100任务/200边拖动期间平均≥30fps；首屏图可交互≤2s | 固定viewport，浏览器性能录制10秒×3，记录长任务；不含模型时间 |
| Q05 P0 恢复 | 重启后已提交历史无丢失；中断规划明确FAILED | 保存、受控结束测试进程、重开并比较hash |
| Q06 P0 模型边界 | 每规划最多3次调用、单次60秒/总180秒；无静默TEST | 虚拟时钟/故障注入检查账本；真实时延另报 |
| Q07 P0 密钥/本地安全 | 前端bundle/API/log无Key；非法Host/Origin拒绝；不执行输入代码 | 静态扫描、请求测试和脱敏检查 |
| Q08 P1 可访问性/扩展性 | 键盘完成核心操作；正常文字对比≥4.5:1；替换Provider不改领域算法 | 自动对比检测+手动键盘；第二个测试Adapter契约测试 |

若目标未达标，记录环境、p50/p95、失败场景，先优化订阅/查询/布局，再调整支持上限；不能无测量宣称支持大型图或高并发。
默认计划上限100任务/1000边是保护边界，不等于所有环境都已证明性能。2026-11-18 基线已完成测量，但仍受记录环境和实现版本约束。

2026-11-18 实测结果、环境、限制和证据见[质量属性验收报告](QUALITY_ACCEPTANCE_REPORT.md)。
