# 设计系统

界面采用浅色默认、深色可选，画布优先。现用样式变量位于 [style.css](../../frontend/src/style.css)。

| 用途 | 变量与规则 |
|---|---|
| 页面、面板、画布 | `--bg`、`--surface`、`--board` 分层；使用细描边和适量留白。深色主题覆盖同一组变量。 |
| 操作与信息 | `--primary` 负责主要操作、选中和焦点；文字使用 `--text` 与 `--text-muted`。同一区域突出一个主要入口。 |
| 校验反馈 | 错误、警告和通过使用 `--danger`、`--warning`、`--success`，配合状态文字。校验通过表示计划状态。 |
| 字体与表单 | 使用 system-ui、Segoe UI、Microsoft YaHei；正文基准 14 px。表单宽度受限，常用字段平铺，补充字段按需展开。 |

## 画布视觉

- 任务卡为 240 × 96 px，标题最多两行；阶段和建议角色与优先级一起显示。有效编排后加批次色边。任务左入右出，依赖连线带箭头，规划图使用静态连线。
- 注释卡为 240 × 108 px，采用浅色暖底或深色暖底，标题栏可拖动，正文区域可编辑及滚动。卡片尺寸固定，避免拖动过程中因重新测量消失。
- 画布沿用点阵背景、浮动工具栏、缩放/适配控制与小地图。宽屏可同时显示索引、画布和详情。

## 可访问性验收

现有按钮使用文本或可访问名称，表单标签与输入关联，依赖也可从详情表单设置。实施验收仍需覆盖键盘操作、焦点回归、颜色对比和窄屏表现；目标见[质量属性](../testing/QUALITY_ATTRIBUTES.md)。
