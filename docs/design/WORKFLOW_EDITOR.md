# 工作流编辑器

## 图投影与状态

- 任务节点 ID 使用 `task_id`，连线由任务的 `dependencies` 派生，方向从上游输出到下游输入。任务列表、索引、详情与画布共用当前草稿。
- 编排产生拓扑批次，任务卡可用批次色边辅以文字标签。业务阶段来自任务的 stage，阶段和并行批次可独立显示。
- 任务、布局与临时选中状态具有各自的更新路径。布局包含位置、视口和注释。拖动时更新画布内的位置，松手才提交布局；显式节点尺寸及端口测量用于保持节点和连线可见。

## 当前交互

| 操作 | 行为 |
|---|---|
| 添加与编辑 | 创建稳定 ID，打开任务详情。任务字段不完整时可保存草稿。任务索引支持名称或 ID 搜索和定位。 |
| 依赖与输入绑定 | 支持拖线或从详情添加上游任务；拒绝重复、自环、闭环及超出上限的连接。输入绑定目前通过详情中的 JSON 字段编辑，来自其他任务的成果须引用直接依赖。 |
| 删除任务 | 确认后移除任务及相关依赖和输入绑定，重新计算时显示现有诊断。 |
| 注释 | 点击画布放置浅黄色注释；拖动标题移动，正文直接输入。注释随布局和本地快照保存，进入 PNG。 |
| 自动布局 | 按依赖从左到右排列任务，并按任务范围聚焦。注释保留原坐标。 |
| 校验与批次 | 必需需求未覆盖、关键假设及跨任务重复假设 ID 阻断；可选需求未覆盖给出警告。通过后可显示批次；内容变化时旧结果失效。 |
| 导出与历史 | 当前 JSON 导出分别提供 Design Spec 和 TaskProposal，PNG 提供画布图像；本地历史只读，支持查看和导出。 |

## 服务端接入与扩展

正式计划消费服务端派生字段和报告，以任务 ID、字段路径和 input_hash 对应当前候选；本地预检用于快速反馈。正式 Layout 独立保存，以版本冲突响应保护本地改动。浏览器历史、业务 PlanRevision 和 PNG 具备各自的用途。

P1 可增加撤销重做、阶段折叠、差异比较与大型图体验。阶段折叠使用视觉代理边，展开后恢复实际任务依赖。性能目标和证据见[质量属性](../testing/QUALITY_ATTRIBUTES.md)及[实现审计](../PROJECT_AUDIT.md)。
