# UI/UX、信息架构与用户旅程

保持 Dify / n8n 式的画布优先布局。主操作从顶栏、当前页面和画布工具栏即可到达，搜索索引和任务详情按需展示。

## 当前页面与布局

| 区域 | 当前行为 |
|---|---|
| 工作台与顶栏 | 创建项目、显式从示例创建、切换项目；显示浏览器保存状态，提供保存、快照、浅色/深色切换。页面导航由当前工作区状态控制。 |
| 设计规格 | 居中表单依次显示产品概况、需求条目、交付与验收，约束和补充说明默认折叠。状态区显示待完善数量，问题可以在字段旁显示。 |
| 任务规划 | 规格通过基础校验后进入。可切换任务列表和工作流；通过编排后查看并行批次。PM 未接入时显示服务状态，入口为手动任务和导入 JSON。 |
| JSON 导入预览 | 左侧是待应用的 JSON，右侧是问题、警告或统计；应用前保留当前计划。结构错误直接提示，结构合法的待修正候选可应用为草稿。 |
| 工作流 | 默认浅色。桌面宽屏默认显示可收起的任务索引，搜索名称或 ID 后定位任务。右侧任务详情按需打开；窄屏下详情移到画布下方，进一步缩窄后索引和导入面板纵向排列。 |
| 本地历史 | 选择快照查看当时的任务与布局，并可导出快照中的规格和任务 JSON。编辑在当前项目草稿中进行。 |

## 状态与反馈

- 空项目与缺少任务是可用的编辑状态。选择「从示例创建」会形成独立 PRESET 项目，默认创建路径仍是空项目。
- 有效编排显示并行批次和统计。任务或规格修改后标记「待重新编排」或显示当前阻断问题；拖动和注释属于布局编辑。
- 必需需求未覆盖、关键假设或跨任务假设 ID 重复时，阻止通过编排；可选需求缺少引用时显示警告。校验结果与浏览器保存反馈各自展示。
- 服务端接入后，规划请求展示排队、生成、需补充信息、失败与成功，明确 REAL/TEST 来源。版本冲突保留本地编辑，再引导用户比较当前服务器版本。
- P2 再提供执行和成果验证。规划状态与真实执行状态使用各自的数据和界面。
