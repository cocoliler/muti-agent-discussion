## 必须额外覆盖的反例

1. Condition 的未选支路包含嵌套 Condition：INACTIVE 必须传递，不能遗留 UNRESOLVED。
2. Parallel 内一支失败、另一支正在执行：停止派发并取消，Join 不应因为失败被当跳过而输出部分成功。
3. 取消与批准同一审批同时发生：事务/代际校验决定唯一有效转移，不能复活取消的 run。
4. 执行器返回大于 1 MiB 输出：明确失败并有错误记录，不能静默截断输出后执行下游。
5. 重试等待期间关闭浏览器：服务继续等待，重启服务则 INTERRUPTED，两者不得混淆。
6. 输入格式符合 schema 但业务断言失败：结果显示失败差异，不能显示“全部验证通过”。

US-01 → US-02 → US-03 → US-04 → US-06 → US-15 → US-07 → US-08/09 → US-11 → US-14，形成一次完整演示。再单独执行冲突、取消、断线、强杀、超限、备份等异常用例。主路径通过不能替代异常路径验收。
