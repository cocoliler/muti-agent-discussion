# 功能优先级与范围控制

状态：设计建议，2026-11-14。P0 表示正式首版必须具备，允许按开发阶段逐项完成，不表示本轮开始实现。权威范围见 [BASELINE](../BASELINE.md)。

## 分类原则

P0 完成规格到验证的完整离线闭环；P1 提高重复操作效率和外部连接能力；P2 需要独立技术论证；Out of Scope 不进入当前路线图。研发新增功能必须说明它解决的实际问题、所依赖能力和验收方式。

| 能力 | 优先级 | 最小交付与划界 | 对应需求 |
|---|---|---|---|
| 本地项目/工作流管理 | P0 | 创建、编辑、搜索、软删除；运行中的对象不允许删除 | FR-01/02 |
| 结构化规格 | P0 | 目标、描述、输入输出、规则、验收和异常处理；关联工作流 | FR-03 |
| 人工任务拆解 | P0 | 职责、依赖、输入输出、完成条件；任务与节点映射及覆盖检查 | FR-04 |
| 基础画布 | P0 | 添加/删除/拖动/连线/断线/复制/多选/缩放/平移 | FR-05 |
| 编辑效率 | P0 | 非嵌套视觉分组、撤销/重做、自动布局、键盘操作 | FR-05 |
| 保存与恢复 | P0 | 自动保存、显式保存、冲突检测；重新打开恢复图与视口 | FR-06 |
| 静态校验 | P0 | 配置、端口、可达性、DAG、类型、引用、分支和任务依赖 | FR-07 |
| 草稿/版本/运行隔离 | P0 | 发布冻结完整定义；草稿测试同样冻结运行快照 | FR-08 |
| 真实本地执行 | P0 | 有限并发、顺序/条件/并行/汇聚、数据传递 | FR-09 |
| 运行控制 | P0 | 安全重试、节点超时、取消、失败收敛 | FR-10 |
| 人工审批 | P0 | 本机同用户决定、持久请求、到期与拒绝处理；不含角色权限 | FR-11 |
| 执行监控与历史 | P0 | SSE、断线补发、节点详情、尝试/日志/输入输出 | FR-12/13 |
| 验证与测试 | P0 | 真实单节点测试、全流程 fixtures、Assert、期望/实际差异 | FR-14 |
| 重启处理 | P0 | 未终态统一 INTERRUPTED；保留记录，手动新建重跑 | FR-15 |
| 应用设置/数据维护 | P0 | 容量/日志保留设置、备份、离线使用、诊断信息 | FR-16 |
| 可扩展内置节点契约 | P0 | 类型/配置/端口与执行器绑定；不支持运行时安装第三方代码 | FR-17 |
| HTTP GET | P1 | 超时/响应限制/网络错误处理；需要网络的流程明确标识 | FR-17 扩展 |
| 工作流 JSON 导入导出 | P1 | schema 版本迁移、未知节点拒绝；不是直接导入第三方 DSL | FR-02 扩展 |
| 模板、历史筛选增强、节点上游缓存调试 | P1 | 保持测试数据与正式数据隔离，避免隐式复用旧输出 | FR-13/14 扩展 |
| 多主题、嵌套视觉组、复杂布局引擎 | P1 | 在桌面核心体验通过后评估；非首版完成条件 | FR-05 扩展 |
| 安全边界上的暂停/续跑、运行检查点 | P2 | 重新设计 in-flight 副作用、状态兼容与恢复测试 | 独立 ADR |
| 循环、子工作流、任意脚本、第三方节点、LLM、凭据库 | P2 | 各自单独评估；任意脚本不因 Worker Threads 就被视为安全 | 独立 ADR |
| CPU Worker 池、独立本地 Worker | P2 | 只有阻塞/故障隔离测量证明需要时引入 | 架构扩展 |
| 云部署/商业多租户/复杂权限/多人实时编辑/分布式执行 | Out of Scope | 不创建相关部署配置、不以可选目录预埋完整基础设施 | 用户最高约束 |
| 移动端复杂画布编辑/全面复制竞品集成市场 | Out of Scope | 首版优化 Windows 桌面浏览器 | 产品边界 |

## P0 节点目录

| 类型 | 配置与结果 | 为什么必要 |
|---|---|---|
| Start | 输入 schema；提供本次 run 输入 | 统一输入入口 |
| Transform | 白名单字段映射、有限运算；输出 JSON | 离线真实任务执行 |
| Template | 文本和显式变量引用；输出字符串 | 生成可查看结果 |
| Condition | 布尔条件 AST；恰选 true/false 出口 | 条件控制 |
| Parallel | 激活全部显式出口 | 清晰表达并行意图 |
| Join | 等所有控制入边 resolved，输出 activeInputs | 正确处理并行等待与互斥跳过 |
| Approval | 决策提示、截止时间；批准后输出决策 | 人工交互 |
| Assert | 白名单比较与预期值；失败给差异 | 验证业务结果 |
| End | 汇总最终输出 | 明确成功出口 |

任务卡是规格中的 TaskItem，不自动等同于一种万能“任务节点”。执行动作由 Transform、Template 等具体类型承担；一个任务可对应多个节点，一个节点至多关联一个任务。这样不会将描述文本误当可执行代码。

## 禁止削弱的首版质量

不能为了提前展示而取消真实执行、事务保存、断线重连、图校验或异常测试；也不能以视觉原型替代它们。进度受限时先延期 P1/P2，P0 内只能调整里程碑，变更首版范围需记录原因和影响。
