# 视觉与组件设计系统

本规范为 FlowStudio 原创设计建议；不是对未提供截图的复刻。P0 优先浅色主题，深色主题 P1；所有资源随应用打包，不使用在线字体或图标服务。查看 [原型](prototype/index.html) 时可对应本规范评审。

## 1. 视觉基调与令牌

以暖白画布、冷灰分隔、单一蓝色操作强调构成专业桌面工具。状态色只出现在小图标、细边框和徽标；不大面积填充节点。

| Token | 值 | 用途 |
|---|---|---|
| `surface.canvas` | `#F5F7FA` | 点阵画布、页面背景 |
| `surface.panel` | `#FFFFFF` | 面板/节点/菜单 |
| `surface.muted` | `#EEF2F6` | 表头、只读区域 |
| `text.primary` | `#17212F` | 标题和正文 |
| `text.secondary` | `#526173` | 辅助说明；不可降为低对比浅灰 |
| `text.muted` | `#64748B` | 时间、次要标签 |
| `border.default` | `#D9E1EA` | 非交互分割线 |
| `border.control` | `#7D8DA1` | 需辨认的输入边界/未激活端口 |
| `action.primary` | `#245DDB` | 主操作/焦点；白字 |
| `action.subtle` | `#EDF3FF` | 选中背景 |
| `status.success` | `#14724B` | 完成图标与文字 |
| `status.warning` | `#885600` | 审批/重试等待 |
| `status.error` | `#BE2633` | 失败与字段错误 |
| `status.neutral` | `#526173` | 待执行/取消/跳过 |

令牌通过 CSS variables 映射 Tailwind/shadcn；禁止组件各自定义第二套主色。状态色必须配图标与文字。非交互分割线不强制 3:1，但交互边界、焦点、端口需要满足目标对比要求。实施时用自动工具检查全部实际背景组合，不能凭本表声称无障碍验收完成。

## 2. 排版、尺寸与间距

- 字体：`Segoe UI, Microsoft YaHei UI, Microsoft YaHei, system-ui, sans-serif`；代码 `Cascadia Code, Consolas, monospace`，不要求安装额外字体。
- 页面标题 24/32px、600；分区标题 16/24px、600；正文与表单 14/22px；表格/节点 13/20px；次要标签 12/18px；代码 12/20px。数字统计 28/34px，不做超大看板。
- 4px 基础间距：4、8、12、16、24、32、48；页面内边距 32px（1366 下 24px）；表格行 48px、紧凑列表 40px。
- 按钮/输入高度 36px，工具栏紧凑按钮 32px；图标按钮可见 32px、命中区域至少 32×32px；画布端口显示 10px，透明命中区域 24px。
- 输入/按钮圆角 6px，节点/面板 8px，弹层 10px；badge 4px，避免所有内容胶囊化。
- 节点静态阴影 `0 1px 3px #17212F0D`；浮层 `0 8px 24px #17212F1A`；面板用边框，不靠阴影区分所有层级。
- 图标同一套 Lucide 风格线性 SVG，16px/20px、1.75px 线宽；类型图标固定，状态图标另外放置。用户节点图标只能来自注册表白名单。

## 3. 组件状态规范

| 组件 | 默认/悬停/选中 | 加载、禁用、错误 |
|---|---|---|
| 主按钮 | 蓝底白字；hover加深；focus外圈2px+2px间隔 | 提交期间spinner+原文；禁用必须可获知原因；失败保留表单 |
| 次按钮 | 白底细边框；hover浅灰 | 危险动作使用红色文字且有具体对象确认 |
| 输入 | 标签在上、说明在下；focus蓝边 | 必填标记配文字；错误红边+图标+可读错误，不只toast |
| 表格行 | hover浅灰；选中浅蓝+左侧标记 | skeleton仅初载；刷新保留旧数据；错误提供重试 |
| 标签页 | 文字+底部线，当前项 `aria-selected` | 不可用项说明原因；键盘左右切换 |
| Toast | 成功短提示、不阻塞；关键错误固定面板 | 不能把未保存/执行中断仅放自动消失toast |
| Dialog/Drawer | 标题、简述、动作；清晰关闭 | Esc关闭非关键层；焦点陷阱/关闭后返回触发元素 |
| JSON结果 | 折叠树/格式化文本、复制、搜索 | 脱敏、截断提示、下载完整结果（在额度内）；不渲染HTML |
| 状态徽标 | 图标+中文状态+必要时英文代码 | 同一种语义在表格、画布、日志保持一致 |

加载从 `idle → pending → succeeded/failed`；按钮不通过固定延时宣布成功。长操作有服务端状态与可取消边界；断线状态和任务失败不能共用文案。

## 4. 节点与运行状态视觉映射

| 状态 | 标识 | 样式与说明 |
|---|---|---|
| PENDING | 空心圆 + 待执行 | 中性边框 |
| READY | 小三角 + 就绪 | 浅蓝徽标，非运行 |
| RUNNING | 转圈 + 执行中 | 蓝色左边框；减少动效时静态图标 |
| RETRY_WAIT | 回转箭头 + 等待重试 | 琥珀徽标，显示第几次尝试/下次时间 |
| WAITING_APPROVAL | 手掌/人像 + 待审批 | 琥珀徽标，操作在详情面板 |
| SUCCEEDED | 对勾 + 已完成 | 绿色细边框/徽标与耗时 |
| FAILED | 叉号 + 失败 | 红色边框和错误摘要 |
| SKIPPED | 斜杠圆 + 已跳过 | 灰色虚线边框；显示未激活原因 |
| CANCELLED | 方块 + 已取消 | 灰色徽标，不显示错误色 |
| INTERRUPTED | 断开图标 + 已中断 | 琥珀边框，注明本地服务退出 |

Run 的 QUEUED 显示排队中；CANCELLING 显示正在取消并禁重复操作。选中蓝色外圈位于状态边框外，两者不得互相覆盖。错误表单不改变历史节点状态。

## 5. 动效与反馈

hover/focus 100–120ms；抽屉显隐 160ms；聚焦节点平移不超过 200ms，连续事件不自动追踪镜头。只让正在运行的少数路径显示轻微流动，禁止所有边永久滚动。`prefers-reduced-motion` 下关闭非必要动画。成功仅根据已提交后端事件呈现，不生成假进度百分比。

## 6. 桌面适配

| 视口 | 编辑器尺寸 | 自适应规则 |
|---|---|---|
| 1920×1080 | 导航56、节点库240、属性360、顶栏56、底部工具40 | 画布至少1264宽（未扣局部边框）；抽屉默认关闭，展开224高 |
| 1366×768 | 导航48、节点库默认收起（展开208）、属性320、顶栏56 | 属性打开时画布998宽；节点库以覆盖式抽屉打开，不再挤压画布；日志抽屉180高且可关闭 |
| 1024–1279宽 | 导航48、属性覆盖320 | 顶部次要操作进菜单；提供全屏画布模式 |
| <1024宽 | 阅读项目、运行详情仍可用 | 编辑器提示桌面宽度需求，保留只读查看；不承诺移动端复杂编辑 |

面板宽度可在限定范围内拖调并本地保存；1366 高度下页面主体内部滚动，不让顶部主操作随表单消失。浏览器 200% 缩放时转窄布局，不隐藏关键错误和退出方式。

## 7. 可访问性验收目标

正文对比至少4.5:1、大字号至少3:1、交互图形至少3:1；focus-visible清晰。所有按钮具有可读名称；表格语义正确；动态运行状态用节流的 `aria-live=polite` 摘要，不逐条朗读高频日志。键盘可创建/选择/移动/配置/删除节点；提供“节点列表 + 连接表单”替代精确拖线。对话框正确管理焦点，Esc 不触发工作流取消。错误汇总能聚焦具体字段。目标以 WCAG 2.2 AA 常用交互准则为验收方向，实际合规需实现后测试；本轮不宣称认证。
