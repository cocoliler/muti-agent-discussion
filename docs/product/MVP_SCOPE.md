# 范围与里程碑
## 当前前端与课堂作业 2 目标

前端分支已支持本地项目、结构化规格、任务导入与编辑、浏览器编排和本地快照。工作台的「会议室预约」由用户显式选择，来源为 PRESET。完整 P0 验收还需接入服务端和 REAL 规划。

## 课堂作业 2 原型
输入现有 Design Spec；PM Agent 输出候选任务；编排器校验并生成拓扑批次；前端任务列表/画布同源显示；人工修改、重算、保存与导出形成闭环。

| 优先级 | 交付范围 | 退出条件 |
|---|---|---|
| P0 | 本地项目；结构化规格及补充文本；JSON 导入导出；规格版本；PM REAL/TEST；结构化任务；依赖/覆盖校验；批次；任务详情；编辑依赖；历史保存；通用验收 | 追踪矩阵全部 P0 验收，有 REAL 证据且无阻断缺陷 |
| P1 | 撤销重做、阶段折叠、差异对比、规划参数体验增强、布局优化 | 不阻塞 P0；具备独立验证记录 |
| P2 | 多 Agent 实际执行、成果管理、SSE、审批、重试、监督、Reviewer 和反馈修订；Markdown/Word/PDF 辅助输入 | Phase 7–9 逐步验收，不纳入作业 2 演示承诺 |
| Out of Scope | 云部署、多租户、计费、实时多人协同、任意脚本插件、分布式调度、无监督发布产品 | 本次及当前团队项目均不开发 |

## 完整项目与当前阶段
最终目标保留可配置 SE 生命周期，角色不固定为五个。作业 2 一个 PM Agent 足够；Orchestrator 是程序模块。
“生成执行计划”按钮不触发 Run。“保存计划”不代表批准实际执行。“并行组”仅表达依赖允许的并行机会。
当前可查看浏览器本地快照，正式版本由后续服务端保存。正式历史读取设计为独立于模型请求，实际执行还需确认快照及工具能力。

## 保留已有成果
保留注释、添加任务、连线、手形模式、整理节点、PNG 和本地草稿。它们是前端基础能力，不能替代真实规格规划。
不在本轮重写前端或引入 UI 框架。文档目录沿用现有结构，新增缺失专篇，避免维护第二套编号目录。
